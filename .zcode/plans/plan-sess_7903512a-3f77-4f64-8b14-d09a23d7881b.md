# harmony DS 全面重设计（校准型，按鸿蒙官方规范）

## Context

用户要求参考华为官方设计理念（One Harmonious Universe + 引力动效体系）全面重新设计页面与交互动效。前置工作已完成：
- 官方 21 页设计文档全量数值已提炼 → `docs/design-spec-harmonyos.md`，并沉淀为用户级 skill `harmonyos-design`（本次执行即按该 skill 走）。
- 现状审计结论：**色板/字号阶梯/断点已高度对齐官方**（色板 95% 逐字一致、Fonts 8 档=官方阶梯、断点 600/840 正确）；缺口集中在——
  1. **动效**：全部为定长 `animateTo({duration, Curve.Smooth})`（42 处），零弹簧曲线、零 stateStyles 按压态、零元素级 transition，与「引力动效」控制感/秩序感要求差距大；
  2. **圆角档位**：现有 8/12/24 vs 官方 4/8/16/20/32 分档（卡片 12→16、按钮/菜单→20、浮层→32）；另有 14.5/18/23/28 等硬编码散点；
  3. **触控热区**：部分包裹层 32–36vp，低于 UX 硬性标准 40×40vp。
- 幅度选择：**校准型**——布局骨架/信息架构不动（已是鸿蒙双栏抽屉范式且真机验证过），动效全面官方化 + 规格校准 + 热区合规修复。

## P0 Token 层（先行，全应用自动受益）

文件：`common/DesignTokens.ets`、`common/Fonts.ets`、`resources/base|dark/element/color.json`

1. **Motion 重构**（`common/DesignTokens.ets`）
   - 保留 animFast/animBase/animSlow 名称（12 个文件在引用，向后兼容），值对齐官方时长分档：200→**150**（小范围/颜色）、240→**200**（局部）、300→**250**（短距离抽屉，满足转场下限 ≥200）。
   - 新增曲线常量（`import { curves } from '@kit.ArkUI'`）：`Motion.curveStd = curves.cubicBezier(0.4,0,0.2,1)`（视线内运动）、`Motion.curveIn = curves.cubicBezier(0,0,0.4,1)`（入场减速）、`Motion.spring = curves.springMotion(0.555, 0.53)`（松手/转场，官方物理弹簧等价参数）、`Motion.springFollow = curves.responsiveSpringMotion()`（跟手）。弹簧曲线不配 duration（传入无效，官方口径）。
2. **Dim 圆角对齐官方分档**：radiusS 8 不动（图片/图标）；radiusM 12→**16**（内容容器/卡片）；radiusL 24→**20**（按钮/菜单/气泡）；新增 radiusXL=**32**（输入面板/浮层大容器）。35 处调用点逐个核对归类（如 ChatInput dock 保持仿官方 28 不改——签名元素）。
3. **色彩微校准**：text_primary/titlebar_icon #E6→**#E5**（官方 font_primary 精确值）；新增 `interactive_pressed`（#19000000 / #19FFFFFF）供按压态使用；其余色板已逐字吻合官方，不动。
4. **Fonts 字重规范**：阶梯数值已吻合官方不动；页面标题（Title 档）字重统一 Bold、副标题/Body_L Medium、Body_M/S Regular（官方字重表）。

## P1 全局交互动效

1. **按压态统一**：Sider 会话行、SettingRow、菜单项、消息操作行、ChatInput 工具 chips 加 `stateStyles({ pressed: { backgroundColor: interactive_pressed } })`；现有 clickEffect 缩放保留（按下即响应 ✓）。
2. **热区修复（硬性标准 2.1.3.3）**：审计全部 ≤20vp 图标直绑事件处（TopControls 胶囊钮、Sider ⋯ 菜单、消息操作行、ChatInput 钮），外包 **≥44vp** 触控容器。
3. **弹簧化**：抽屉松手吸附与 Index.onBackPress 收抽屉 → springMotion；思考折叠块展开/收起 → spring；附件三卡面板、上下文 popup、队列 chips 进出场 → transition+spring。
4. **秩序感编排**：欢迎态图标/标题错峰入场（150/200ms 减速曲线，delay 编排）；新消息气泡入场 150ms fade+上移（仅终态渲染，流式路径零改动——ForEach 稳定键 f\${i}/bk\${idx} 保持不动）。
5. **沉浸光感对齐**：TopControls 顶部胶囊 blur 升级 COMPONENT_ULTRA_THIN；输入 dock 保持 COMPONENT_THIN（底部悬浮，符合官方建议）。
