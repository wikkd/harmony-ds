## 应用介绍

**中文**

    harmony DS 是一款鸿蒙原生的 AI 对话客户端，采用 ArkUI 原生开发，兼容 DeepSeek 开放接口——使用你自己的 API Key，即可随时与 DeepSeek 模型对话。本应用为独立开发的第三方工具，与深度求索公司无隶属关系。

    【核心功能】
    • 流式对话：逐字输出、随时停止、失败重试
    • 深度思考：思考过程完整展示，支持三档思考强度
    • 智能搜索：联网检索，回答附引用来源
    • 富文本渲染：Markdown、代码高亮、LaTeX 数学公式
    • 分支对话：编辑重发、重新生成、多版本自由切换
    • 图片理解：拍照、相册、文件作为附件直接提问
    • 语音朗读：回复流式朗读，双音色可选
    • 消息通知与实况窗：后台回复完成即时提醒

    【隐私安全】
    无账号体系、无统计埋点、无广告 SDK。对话数据仅存本机，API Key 经系统关键资产加密存储；支持一键导出与一键删除全部数据。

    【AI 生成内容提示】
    AI 生成内容可能存在错误，请注意甄别。应用内 AI 内容均标注"内容由 AI 生成"。AI 能力由 DeepSeek 提供，服务方已完成生成式人工智能备案与算法备案（算法备案号：网信算备330105747635301240017号）。

    【多设备适配】
    手机、平板双适配：宽屏双栏布局，支持折叠屏展开态、分屏与自由窗口。

**英文**

    harmony DS is a native HarmonyOS AI chat client built with ArkUI, compatible with the DeepSeek API — bring your own API Key and chat with DeepSeek models anytime. This app is an independently developed third-party tool and is not affiliated with DeepSeek.

    [Key features]
    - Streaming replies: token-by-token output, stop anytime, retry on failure
    - Deep thinking: full reasoning display with three effort levels
    - Web search: answers with cited sources
    - Rich rendering: Markdown, code highlight, LaTeX math
    - Branching: edit & resend, regenerate, switch between versions
    - Image understanding: attach photos, albums or files
    - Read aloud: streaming TTS with two voice options
    - Notifications & Live View: know when a background reply finishes

    [Privacy]
    No account, no analytics, no ads SDK. Chats stay on your device; your API Key is encrypted in the system key store. One-tap export and erase.

    [AI content notice]
    AI-generated content may be wrong; use your own judgement. All AI content is labeled "Generated by AI". AI capability is provided by DeepSeek, whose generative AI service and algorithm are duly filed (algorithm filing No. 网信算备330105747635301240017号).

    [Multi-device]
    Phone and tablet ready: two-pane wide layout, foldable, split-screen and free-window support.

## 宣传视频（可选素材）

无需上架硬性要求，建议用平板自带录屏（控制中心 → 屏幕录制）录 20–30 秒竖版或横版：

1. 0–5s：欢迎态 → 点输入框打字"介绍量子纠缠"
2. 5–15s：回复流式输出 → 展开"已思考"折叠块
3. 15–22s：侧栏切会话 → 演示 ‹ 2/2 › 分支切换
4. 22–30s：设置页快速滑过 → 停在「AI 服务信息」页（备案号可见）

要点：全程真机操作、不加速到看不清、不出现在任务栏通知等无关内容；如配乐需无版权。
